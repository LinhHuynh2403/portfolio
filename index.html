AI Engineering Intern · Helix International (acquired by IBM)

I worked on an internal tool that lets customers query their own data in plain English instead of filling out forms or requesting manual exports. Since the language models needed more compute than my laptop could handle, I set up vLLM on a GPU desktop and ran it remotely to test open-source models like Qwen, Llama, and Gemma. Most of my time went into building the evaluation set — I wrote 70+ realistic user questions in YAML with hand-written expected SQL answers, then ran each model against them, tuning prompts, temperature, and context window to cut down hallucinations until we reached about 90% accuracy. I also built a simple frontend near the end to help the team sanity-check the frontend–backend–API connection, and documented the testing and prompt-engineering process for the team.
